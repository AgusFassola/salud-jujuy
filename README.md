\# 🏥 Salud Jujuy - Directorio Inteligente y Gestión de Turnos



Plataforma web diseñada para centralizar y facilitar el acceso a profesionales de la salud en \*\*San Salvador de Jujuy\*\*, con arquitectura escalable hacia toda la provincia (Palpalá, Perico, Quebrada y Puna).



\## 🎯 Problema que resuelve

Actualmente en Jujuy, encontrar un especialista disponible que acepte una obra social específica (como el \*\*ISJ\*\*), atienda en un barrio o punto de referencia cercano y tenga turnos en una franja horaria puntual requiere llamadas telefónicas interminables o traslados innecesarios.



\## ✨ Funcionalidades Principales (MVP)

\- \*\*Búsqueda Multifacética en Tiempo Real:\*\* Filtrado por especialidad, obra social (ISJ, OSDE, PAMI), barrio/referencia geográfica (ej. Gorriti / Plaza de los Inmigrantes), tipo de centro (Hospital, Clínica, Consultorio), franja horaria y costo máximo.

\- \*\*Portal de Pacientes:\*\* Reserva directa de turnos en 3 pasos con persistencia en base de datos.

\- \*\*Portal de Profesionales:\*\* Alta autogestionada con validación de Matrícula Profesional (MP Jujuy) y actualización instantánea en el directorio.

\- \*\*Visión Provincial:\*\* Selector preparado para expansión regional por localidades jujeñas.



\## 🛠️ Stack Tecnológico

\- \*\*Frontend:\*\* HTML5 Semántico, CSS3 (Grid/Flexbox responsivo), JavaScript ES6+.

\- \*\*Base de Datos \& API:\*\* PostgreSQL alojado en Supabase con Row Level Security (RLS).

\- \*\*Despliegue:\*\* Netlify \& GitHub.
